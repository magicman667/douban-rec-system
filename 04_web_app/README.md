## 核心研发任务
1. **Mock 数据先行解耦**：编写 `mock_gen.py` 严格按照 5 项冻结契约生成本地模拟表，零等待搭建 Streamlit + Plotly / ECharts 暗黑风前端。
2. **纯享版双视图推荐产品**：
   - **视图一【千人千面电影推荐大厅】**：典型用户切换、题材筛选、自然语言情境搜片、MongoDB 实时流式口碑异动跑马灯、防盗链高清海报墙（`<img referrerpolicy='no-referrer'>`）、争议电影右侧详情抽屉（1～5 星波形图 + AI 正反方口碑排雷卡 + 3 部 Weaviate 同类型零差评平替片）。
   - **视图二【不同类型电影差异全景馆】**：20+ 种题材 1～5 星山脊波形图（Ridgeline Plot）、“题材 × 分歧”四象限发光散点图、可旋转 3D 全球及华语产区类型地球仪、各类型高频中文标签词云。
3. **独立【数据洞察】页面（`analysis_dashboard.py`）**：按固定路径读取 `../analysis/` 下 1、2、3 号交付的真实 CSV/PNG 进行可视化呈现，不重新计算指标。
4. **演示录屏与报告/答辩统合**：录制 90 秒高清实操 MP4，统合课程报告排版与 5 分钟课堂答辩 PPT。
